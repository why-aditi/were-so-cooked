# Spike 6 — AI Gateway caching on the free plan

**Question (spec section 14):** Is AI Gateway caching available on the free plan?

**Decides:** Demo caching strategy.

**Run at:** 2026-09-25T05:30:47.986Z

## Answer

**Yes.** Identical requests through gateway `cooked-spike6` came back as `HIT` on repeat, in **177 ms** against **2488 ms** cold (14.1x faster), and a cached response does not reach the model, so it costs no neurons. Section 12's demo caching strategy works: give every demo suggestion chip byte-identical context and repeat reviewers cost nothing.

## What this changes

- **Demo strategy:** the suggestion chips in section 12 must send byte-identical context, including the system prompt and any timestamp. One varying token and the cache never hits.
- **Budget:** a cached turn costs 0 neurons, so repeat reviewer sessions are close to free. The "about 6 sessions a day" figure in section 12 is a floor, not a ceiling.
- **Cache busting:** `skipCache: true` works, so real user turns can opt out while demo chips opt in.
